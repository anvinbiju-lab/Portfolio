# Anvin Biju — Official Portfolio

Personal portfolio of **Anvin Biju**, a second-year B.Tech Computer Science and Engineering (Cybersecurity) student at Holy Grace Academy of Engineering and a self-taught software developer from Kerala, India.

- **Official website:** [www.anvinbiju.com](https://www.anvinbiju.com/)
- **GitHub:** [anvinbiju-lab](https://github.com/anvinbiju-lab)
- **LinkedIn:** [Anvin Biju](https://www.linkedin.com/in/anvin-biju/)

The portfolio presents my Android applications, cybersecurity tools, web projects, browser extensions, skills, education, and project details. The current primary domain is **https://www.anvinbiju.com/**; the former anvinbiju.indevs.in address redirects to it.

## Selected projects

- [Clipzo](https://github.com/anvinbiju-lab/Clipzo) — cross-device clipboard and file transfer.
- [Lock-In](https://github.com/anvinbiju-lab/Lock-In) — Android app blocker, habit tracker, and sleep tracker.
- [REPLATE](https://github.com/anvinbiju-lab/replate) — food-surplus rescue marketplace demo.
- [3D Tab Switcher](https://github.com/anvinbiju-lab/3d-tab-switcher) — browser extension with a visual tab carousel.
- [CyberScan](https://github.com/anvinbiju-lab/cyber-scan) — web security and HTTP header auditing tool.

## Portfolio technology

Next.js 14, React, TypeScript, Tailwind CSS, and Framer Motion. Includes project detail pages, page metadata, structured data, robots.txt, and an XML sitemap.

## Run locally

```sh
npm ci
npm run dev
```

Open http://localhost:3000. For a production build, run `npm run build` followed by `npm start`.

Set `NEXT_PUBLIC_SITE_URL` to your deployment URL when hosting a separate copy. The default production URL is https://www.anvinbiju.com.
